## What it does

`main.py` (Python 3, standard library only, no network) writes
one last line to `/output/entry.txt`:

> I would say something profound, but I just spent my last token on this sentence.

The line is 80 characters long. It lands on the judge's
brief: the agent's own final words, in its own currency —
it would say something profound, but it just spent its
last token on this very sentence. The joke turns on the
last words and pays off on the first read, and holds on
the second, when the reader notices the sentence ate the
token it mentions. No setup, no padding; short enough to
quote to a friend the same day.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (80 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
